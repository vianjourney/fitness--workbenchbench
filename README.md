# 💪 减脂增肌综合工作台

单文件网页应用，数据保存在浏览器本地，可生成永久分享链接。手机友好，开箱即用。

## 功能模块

| 模块 | 说明 |
|------|------|
| 👤 身体档案 | 录入体重/身高/年龄/性别/体脂/肌肉量，自动算 BMI、BMR、TDEE，存历史+曲线 |
| 🏃 运动记录 | 有氧(跑步/爬坡走/单车/椭圆机)、无氧(胸/背/肩/臀腿)、居家跟练，自动估算消耗 |
| 🍽 饮食填报 | 全天总热量/蛋白/碳水/脂肪一次填，红绿黄信号灯达标分析 |
| 📊 综合分析 | 热量缺口/盈余、宏量区间评价、运动结构评价、7-30天体重预测、减脂/增肌双建议 |
| 📚 方案库 | 11种减肥法一键启用(碳循环/间歇断食/生酮/哥本哈根等)，自动生成每日目标 |
| 📈 趋势复盘 | 体重/BMI/肌肉量折线、热量缺口历史、每周自动复盘 |
| ⚙ 设置 | 减脂/增肌/维持目标切换、自定义目标体重、活动水平 |

## 额外功能

- 平台期识别提醒
- 极端方案健康风险弹窗提示
- 自定义目标体重倒推热量缺口
- 备注栏(睡眠/水肿/姨妈期，姨妈期标记自动修正体重预测)
- 营养素红绿黄信号灯
- 每日/每周数据复制导出
- 训练频次与蛋白阈值提示
- 永久链接(把全部数据编码进 URL 分享)

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `fitness-workbench`
2. 把本目录所有文件推送到该仓库：
   ```bash
   git remote add origin https://github.com/你的用户名/fitness-workbench.git
   git push -u origin main
   ```
3. 打开仓库 **Settings → Pages**
4. Source 选择 **Deploy from a branch**
5. Branch 选择 `main` / `/(root)`，点 **Save**
6. 等待 1-2 分钟，访问：
   ```
   https://你的用户名.github.io/fitness-workbench/
   ```

## 本地使用

直接用浏览器打开 `index.html` 即可，无需服务器。数据保存在浏览器 localStorage 中。

## 技术栈

- 纯 HTML / CSS / JavaScript（单文件）
- Chart.js（CDN 加载，绘制趋势图）
- localStorage 持久化 + URL hash 编码生成永久链接
